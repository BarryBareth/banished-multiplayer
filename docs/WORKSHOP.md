# Steam Workshop page

Suggested title and description for the Workshop item (`bmpShare.pkm`). Steam's description supports BBCode.

**Title:** Banished Multiplayer

**Description:**

```
[h1]Play Banished together with other players[/h1]

Share one town, or each build your own town on the same map - and trade, share storage and workplaces.

[h2]This mod does nothing on its own[/h2]
It is the companion file of Banished Multiplayer. The multiplayer itself is a small program file (dinput8.dll)
that you install once from the project page:

[url=https://github.com/BarryBareth/banished-multiplayer]github.com/BarryBareth/banished-multiplayer[/url]

Download the newest release zip there and run Install.bat. It notices this Workshop subscription and only installs
the program file. Without it, the main menu shows a reminder.

[b]What the program file does:[/b] Banished's mod system can't add new code, so the multiplayer is a DLL that the
game loads when it starts. It hooks into the game to keep everybody's game in sync over the network (Steam, a relay
server, or a direct connection). The full source code is on the project page. Antivirus programs sometimes warn about
DLLs that hook into games; that's expected for this kind of mod.

[h2]Requirements[/h2]
[list]
[*] The Steam version of Banished 1.0.7 (the normal 64-bit game), Windows 10/11
[*] Everybody in a game needs the same version (the game tells you if not)
[/list]

[h2]Problems and bug reports[/h2]
Use the bug button in the Multiplayer window or the in-game bar, or open an issue on the project page.
```
